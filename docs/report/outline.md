# Technical report outline

Cover: title, authors, course, topic, teacher, date.
1. Abstract: write actual results after testing.
2. Introduction: theory, problem, use-case diagram.
3. Development: agent type, PEAS table, environment properties,
   component diagram, state model and data structures.
4. Search strategies: BFS/A*, g(n), h(n), assumptions and guarantees.
5. Documented source: classes/functions and solution reconstruction.
6. Execution evidence: numbered screenshots and efficiency comparison.
7. Conclusions and improvements.
8. References in APA format.
9. Appendices.

Follow the instructor's detailed subsection numbering in the final report.
Add an index/list of screenshots and figures. Do not invent performance results.
